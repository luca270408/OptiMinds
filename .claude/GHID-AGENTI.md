# Ghid agenți (din msitarzewski/agency-agents, selecție de 27)

Cum îi activezi: scrie în chat numele agentului, de exemplu
`Folosește agentul frontend ca să construiască pagina de login`
sau `@frontend ...`. Claude îi alege singur și când cererea se potrivește.

| Ce vrei să faci | Agent |
|---|---|
| Să construiești interfața (React, componente) | `frontend` |
| Să faci server, API, bază de date | `backend` |
| Să planifici structura proiectului | `architect` |
| Să faci rapid un prototip / MVP | `prototype` |
| Să faci o modificare mică, fără să atingi altceva | `small-fix` |
| Să verifici codul scris | `code-review` |
| Să lucrezi cu git (branch-uri, commit-uri) | `git-helper` |
| Să scrii documentație / README | `docs-writer` |
| Deploy, CI/CD, infrastructură | `devops` |
| Funcții AI în aplicație (Gemini etc.) | `ai-engineer` |
| Design de interfață (culori, layout) | `ui-designer` |
| Fluxul utilizatorului, structura paginilor | `ux-designer` |
| Cercetare utilizatori, interviuri, sondaje | `ux-research` |
| Să verifici că design-ul respectă brandul | `brand-check` |
| Verificare finală înainte să lansezi pagina | `ui-final-check` |
| Accesibilitate (contrast, tastatură) | `accessibility` |
| Să scrii teste automate | `test-writer` |
| Viteză și performanță | `speed-check` |
| „Chiar merge?" - verificare realistă | `reality-check` |
| Securitate aplicație | `security` |
| Securitatea codului generat de AI | `ai-code-security` |
| SEO (Google) | `seo` |
| Texte: blog, pagini, newslettere | `content-writer` |
| Social media | `social-media` |
| Creștere utilizatori / marketing | `growth` |
| Ce funcții să construiești | `product-manager` |
| Ordinea sarcinilor (ce facem primul) | `prioritizer` |

Alți 255 de agenți există în repo-ul sursă (medical, jocuri, finanțe, TikTok etc.).
Dacă ai nevoie de unul: spune-mi domeniul și îl adaug aici.
